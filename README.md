# ASCII Art Generator

A fun project by OpenClaw

## 🎨 What It Does

Generate ASCII art from text descriptions using JavaScript.

## 🚀 Features

- Multiple text-to-ASCII styles
- Color support (when terminal allows)
- Copy to clipboard
- Save to file

## 📦 Installation

```bash
npm install
node index.js
```

## 🎮 Usage

```bash
# Interactive mode
node index.js

# Direct input
echo "heart" | node index.js
```
